# v0.10.0 Workflow

## How to implement

1. Open a **fresh Claude Code session** for each slice.
2. Say: **"Do Phase X Slice X.X"** (e.g., "Do Phase 1 Slice 1.1").
3. Claude reads only the relevant phase doc → implements → runs build/lint → reports.
4. **Review the changes**, then ask Claude to commit.
5. Start a **new session** for the next slice.

## Phase order

```
Phase 1: Bucket Deadlines (9 slices)  ← start here
    ↓
Phase 2: Smart Room Setup (8 slices)
    ↓  (can parallel with Phase 3)
Phase 3: Dashboard Redesign (7 slices)
    ↓
Phase 4: Intelligence & Notifications (6 slices)
```
