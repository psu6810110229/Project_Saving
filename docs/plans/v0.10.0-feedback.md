## User Review Required

> [!IMPORTANT]
> **F1+F2 — Vault Card decision**: Users want the old credit-card vault aesthetic but with "me-first" data (personal goal + status, NOT room data). The deposit button should also be removed from the card. This means we'll create a **hybrid card**: the old `TotalVaultCard` visual style, but displaying **personal** saved/target/progress instead of room totals, and **without** the deposit CTA. The room name stays in the "Valid thru" footer. The deposit flow will use the existing drag-to-bucket-card → BucketSheet flow that users love.

> [!IMPORTANT]
> **F3 — Head-to-Head vs Team Section**: Users prefer the old 2-player `HeadToHeadCard` over the new `TeamSection` with the 3-column Team grid. We'll bring back `HeadToHeadCard` as the default for rooms ≤ 3 members and keep `TeamSection` only for rooms with 4+ members (where a 1v1 comparison doesn't make sense).

> [!WARNING]
> **F5 — Privacy**: Users are strongly opposed to seeing other members' buckets. We will **completely remove** the `BucketMemberPicker` tab bar and all `otherMemberBucketGroups` rendering. Users will only ever see their own buckets on the dashboard. Other members' progress is still visible via the head-to-head / team section (saved vs target), but individual bucket details are private.

## Open Questions

> **Q2**: Decided **(B)** — Keep navigation for others but remove self-tap → profile.

### Phase D — Consistency (P1: F9)

---

#### Work Item 9: Normalize Button Labels (F9)

Users report inconsistent button labels across drawers and modals. The feedback specifically calls out: Back, Profile, Dashboard, กลับ, ย้อนกลับ, ยกเลิก, cancel, ไปเลย, ตกลง, เข้าใจแล้ว, ถัดไป — all used for similar "return" or "confirm" actions.

##### [MODIFY] [en.ts](file:///d:/Fran's%20Folder/Project/src/i18n/locales/en.ts)
##### [MODIFY] [th.ts](file:///d:/Fran's%20Folder/Project/src/i18n/locales/th.ts)

Standardize to **3 core action labels** across all modals/drawers:

| Action | English | Thai |
|--------|---------|------|
| Go back / close drawer | **"Back"** | **"กลับ"** |
| Cancel / dismiss | **"Cancel"** | **"ยกเลิก"** |
| Confirm / proceed | **"Done"** | **"เสร็จสิ้น"** |

**Audit all components** for non-standard labels:
- Modal close buttons → "Back" (กลับ)
- ConfirmModal cancel → "Cancel" (ยกเลิก)  
- Success/outcome modals → "Done" (เสร็จสิ้น)
- Bottom sheet dismiss → "Back" (กลับ)
- Wizard next/proceed → "Next" (ถัดไป) — this is fine, keep it
- Wizard final step → "Done" (เสร็จสิ้น)

**Icon consistency**:
- Back → left arrow (←) everywhere
- Close → X icon everywhere (no mixing)
