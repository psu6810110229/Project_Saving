# Phase 3: Dashboard Redesign

## Context

Phase 3 rebuilds the dashboard from room-centric to me-first. The Hero Card shows personal progress + daily target + deposit button. Buckets sort by urgency. A compact team section shows the mini leaderboard. Action alerts surface behind/critical buckets. The separate `/add` page is retired in favor of inline deposit on the dashboard.

**Prerequisites**: Phase 1 complete (pace data, focus states, daily summary available).
**Can run in parallel with**: Phase 2 (no dependency on templates/wizards for dashboard rendering).

**Key decisions**: D37-D42

**Critical files to read before starting**:
- `src/pages/Dashboard.tsx` — current dashboard (900+ lines, major rewrite target)
- `src/components/TotalVaultCard/TotalVaultCard.tsx` — current vault card (credit card aesthetic)

- `src/pages/AddMoney.tsx` — current deposit page (to be retired)

## Slice 3.4: Bucket Zone — Urgency Sort & Completed Section

**Status**: [ ] pending

### What
Restructure the bucket display area: active buckets sorted by urgency (focus first, then by deadline), completed buckets in a separate collapsed section.

### Files to touch
- `src/components/BucketGrid/BucketGrid.tsx` (modify)
- `src/components/BucketRow/BucketRow.tsx` (minor adjust if needed)

### Implementation detail

**Sort order**:
1. `overdue` buckets first (urgent)
2. `focus` buckets (current)
3. `next` bucket
4. `queued` buckets (by deadline ascending)

**Completed section**:
- Below active grid, collapsed by default.
- Header: "Completed (3)" with expand/collapse chevron.
- Completed buckets show: name + target + ✓ + completion date.
- Simpler card layout (no countdown, no pace — they're done).

**Edit mode toggle** (new):
- Current behavior: drag = transfer money between buckets.
- Add edit mode toggle button: when active, drag = reorder buckets.
- Visual distinction: edit mode shows drag handles, transfer mode shows transfer arrows.

### Acceptance criteria
- [ ] Buckets sort by urgency (overdue → focus → next → queued)
- [ ] Completed section collapsed by default
- [ ] Edit mode vs transfer mode distinguishable
