# v0.10.0 Master Plan — Bucket Deadlines, Smart Room Setup & Dashboard Redesign

## Overview

v0.10.0 transforms buckets from passive money containers into active, deadline-driven saving goals with per-bucket saving rules, pace tracking, and intelligent warnings. Rooms gain an expense timeline that helps creators plan payment schedules, and members receive guided onboarding. The dashboard shifts from room-centric to me-first, showing the user exactly what to save today.

**Scope**: Travel category only for smart suggestions. Non-travel categories deferred.

### Buckets
| # | Decision | Detail |
|---|----------|--------|
| D7 | Every bucket must have a deadline | Required field; no deadline = no pace tracking is not an option |
| D8 | Shared Bucket Templates | Creator defines expenses → system creates buckets for all members |
| D9 | Overfunding allowed | Show clearly as 106%, no lock |
| D10 | Complete buckets can be edited/deleted | Target editable; deletion allowed (financial history preserved in logs) |

| D13 | All icons SVG | Use existing `Icon` component system; no emoji in UI |

### Bucket Saving Rules
| # | Decision | Detail |
|---|----------|--------|
| D14 | 6 rule types | `fixed_daily`, `fixed_weekly`, `fixed_monthly`, `increasing_daily`, `increasing_daily_capped`, `flexible` |
| D15 | `flexible` = no rhythm | No daily/weekly/monthly target; pace tracked by checkpoint milestones only |
| D16 | Monthly reminder day | User chooses (forced); system reminds on that day if not yet deposited this month |
| D17 | Creator sets suggested rule per template | Members accept or change to own rule |
| D18 | Period-aware tracking | Each rule tracked against its own period, not normalized to daily |

### Sequential Focus
| # | Decision | Detail |
|---|----------|--------|
| D19 | Max 2 focus buckets at a time | Prevents cognitive overload |
| D20 | Focus = nearest-deadline incomplete bucket | Auto-computed; user can override |
| D21 | "What to save today" = focus buckets only | Daily rules show daily amount; monthly shows "X days until due"; flexible shows % progress |
| D22 | Streak = focus bucket period compliance | daily rule → daily streak; monthly rule → monthly streak; flexible → no streak |
| D23 | Non-focus buckets don't trigger warnings | Queued buckets are silent until they become focus |
| D24 | 3+ overlapping deadlines → suggest revision | Alert user to adjust deadlines or merge buckets |

### Pace & Warnings
| # | Decision | Detail |
|---|----------|--------|

| D26 | 4 warning levels | Ahead (≥10% over), On-track (within tolerance), Behind (≥1% under), Critical (<30% time + <70% saved) |
| D27 | Warnings on dashboard + push + in-app | Push when status changes (e.g., on-track → behind) |
| D28 | Visibility: status for all, details for self | Other members see ahead/on-track/behind badge; own buckets show full numbers |

## Schema Overview (New/Modified)

### Modified Tables

**`buckets`** — add columns:
- `deadline` date NOT NULL (new buckets); nullable during migration window
- `saving_rule_type` text (enum: fixed_daily, fixed_weekly, fixed_monthly, increasing_daily, increasing_daily_capped, flexible)
- `saving_rule_amount` numeric (for fixed_* rules)
- `saving_rule_start_amount` numeric (for increasing_daily)
- `saving_rule_increment` numeric (for increasing_daily)
- `saving_rule_cap` numeric (for increasing_daily_capped)
- `saving_rule_day_count` integer (for increasing_daily_capped)
- `reminder_day` integer (1-28, for monthly rules; user-selected)
- `payment_type` text (advance_booking, pre_trip, on_trip, flexible)
- `completed_at` timestamptz (set when saved ≥ target)

**`rooms`** — add columns:
- `cover_image_url` text (Supabase Storage path)

**`notification_preferences`** — add columns:
- `bucket_alerts_enabled` boolean DEFAULT true
- `achievements_enabled` boolean DEFAULT true
- `team_updates_enabled` boolean DEFAULT true

### New Tables

**`expense_templates`** — shared bucket templates created by room creator:
- `id` uuid PK
- `room_id` uuid FK rooms
- `category` text (bucket category enum)
- `name` text
- `target_amount` numeric
- `payment_type` text
- `deadline` date
- `suggested_rule_type` text
- `suggested_rule_amount` numeric
- `priority` integer (display/focus order)
- `tip_key` text (i18n key for smart suggestion tip)
- `created_by` uuid FK auth.users
- `created_at` timestamptz

**`bucket_deadline_revisions`** — audit trail for deadline changes:
- `id` uuid PK
- `bucket_id` uuid FK buckets
- `previous_deadline` date
- `new_deadline` date
- `changed_by` uuid FK auth.users
- `changed_at` timestamptz
